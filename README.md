# SEAT/MAP — 교실 자리 배정 시스템

선생님을 위한 **랜덤 자리 배정 웹앱**입니다.
설치 없이 브라우저에서 바로 쓰고, 학생 정보는 **어디에도 전송되지 않습니다.**

👉 **바로 사용하기: https://stvh8120-glitch.github.io/seat/**

---

## 주요 기능

### 학생 목록
- **직접 입력**: 한 줄에 한 명씩 입력하고 `Ctrl+Enter`로 추가
- **파일 불러오기**: `txt`, `csv`, `xlsx` 지원 (드래그 앤 드롭 가능)
- **번호 자동 인식**: `3 김민준`, `3. 김민준`, `3번 김민준`처럼 쓰거나, 엑셀 A열에 번호·B열에 이름을 넣으면 명렬표 번호로 사용
- **비고 자동 인식**: `김민준(반장)`처럼 괄호 안의 내용은 명렬표 `비고`란으로 분리
- `번호 / 이름` 같은 머리글 행은 자동으로 건너뜀

### 랜덤 배정
- 5초 카운트다운 후 공개되는 배정 연출
- 화면 맨 위 헤더와 사이드바 어디서든 배정 가능
- **특별 조건**
  - 🚫 떨어뜨리기: 두 학생이 붙어 앉지 않게
  - 💛 붙이기: 두 학생이 가까이 앉게
- **📌 앞자리 고정**: 체크한 학생은 앞쪽 줄부터 배치
- **📍 지정석**: 특정 학생을 원하는 자리에 고정

### 자리 조작
규칙은 하나입니다. **학생을 누르고, 옮길 자리를 누르면 두 자리가 서로 바뀝니다.**

| 먼저 누른 것 → 다음에 누른 것 | 결과 |
|---|---|
| 학생 → 다른 학생 | 서로 자리 교환 |
| 학생 → 빈자리 | 그 자리로 이동, 원래 자리는 빈자리 |
| 학생 → ✕ 자리 | 그 자리로 이동, 원래 자리가 ✕ |
| (선택 없이) 빈자리 / ✕ | ✕(사용 안 하는 자리) 켜기 / 끄기 |

- 선택 취소: 같은 자리 다시 클릭 · `Esc` · 배치도 바깥 클릭
- **↶ 되돌리기 / ↷ 다시 실행**: `Ctrl+Z` / `Ctrl+Y` (최대 100단계)
- **↺ 초기화**: 배치만 지우고 학생·✕·지정석·조건은 유지합니다. 확인 창에서 `Enter`를 누르면 초기화되고, 초기화한 뒤에도 되돌리기로 복구할 수 있습니다.
- **⇅ 뒤집기**: 교사 시점(교탁 위)과 학생 시점(교탁 아래)을 전환

### 좌석 현황
배치도 오른쪽 아래에 **남은 좌석 / 남은 학생**이 실시간으로 표시됩니다.
- 배정 전: 랜덤으로 채울 자리와 학생 수를 보여 주고, 자리가 부족하면 경고
- 배정 후: 빈자리 수와 자리 없는 학생 수를 표시

### 인쇄 & 명렬표
- A4 가로 한 장에 자리 배치도 인쇄
- 좌석 블록은 용지 위아래 가운데에 정렬되고, 인쇄할 때는 앞자리 고정·지정석 색상 없이 테두리가 통일됨
- **명렬표 함께 인쇄**(선택)
  - 배치도 **왼쪽 / 오른쪽** 중 위치 선택
  - 학생 목록으로 자동 작성하고, 번호·이름·비고를 직접 편집 가능
  - `⠿` 손잡이로 **드래그 앤 드롭** 순서 변경 (마우스·터치 모두 가능)
  - 제목과 추가 열 이름(예: 비고, 1인1역) 설정
  - 학생이 많으면 자동으로 2~3단으로 나눠 한 장에 맞춤
- 📄 PDF 저장

### 배치 기록 (누적 배정)
- 현재 배치를 **비밀번호로 암호화한 JSON 파일**로 저장 (AES-GCM 256, PBKDF2)
- 다음 배정 때 기록 파일을 불러오면 **이전과 같은 자리·옆자리를 피하도록** 배정
- 기록이 쌓일수록 매번 더 다양한 배치가 나옴

## 개인정보 보호

- **단일 HTML 파일**로 동작하며 서버가 없습니다.
- `Content-Security-Policy`로 **모든 외부 연결을 차단**합니다(`connect-src 'none'`). 학생 이름이 외부로 나갈 수 없습니다.
- 외부 라이브러리를 쓰지 않습니다. xlsx 읽기, PDF 생성, 암호화 모두 브라우저 내장 기능으로 처리합니다.
- 브라우저에는 **화면 테마와 인쇄 설정만** 저장합니다. 학생 이름은 저장하지 않습니다.
- 배치 기록 파일은 암호화되어 있어서, 비밀번호 없이는 내용을 볼 수 없습니다.

## 사용 방법

1. **교실 설정**: 행(앞뒤)·열(좌우) 수를 입력합니다. (최대 12 × 12)
2. **학생 추가**: 직접 입력하거나 명단 파일(txt / csv / xlsx)을 끌어다 놓습니다.
3. **자리 설정**(선택): 안 쓰는 자리는 클릭해서 ✕로 만들고, `📍 지정석 설정` 탭에서 지정석을 정합니다.
4. **조건 설정**(선택): 떨어뜨리기·붙이기 조건과 앞자리 고정(📌)을 지정합니다.
5. **🎲 랜덤 자리 배정**을 누릅니다.
6. 필요하면 자리를 클릭해서 조정합니다.
7. **🖨 인쇄**하거나 **💾 기록**으로 저장합니다.

### 명단 파일 예시

**txt**
```
1 김민준(반장)
2 이서연
3. 박지호(부반장)
최유나
```

**csv / xlsx**

| 번호 | 이름 |
|---|---|
| 1 | 김민준(반장) |
| 2 | 이서연 |
| 3 | 박지호 |
